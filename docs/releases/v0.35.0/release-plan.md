## Риски

- Основные риски: после обновления пакета `make deptrac` и проверки `PHPCS` в проектах-потребителях покажут ранее скрытые нарушения; потребители должны завести задачи на их устранение
- Наличие миграций данных: отсутствуют (пакет не хранит данных)
- Порядок применения миграций: не применим
- Несовместимые изменения:
  - Deptrac: слой изолированных объектов встраивания сущности запрещён для всего, кроме моделей сущностей; правила `Application` прописаны явно вместо транзитивного замыкания — ранее скрытые зависимости станут нарушениями
  - Deptrac: класс вне замкнутого каталога типов `Domain` и объекты в слое `ValueObject` без суффикса `Vo` становятся ошибками
  - `PHPCS`: свойства объекта значения должны быть приватными (включая promoted), типы свойств классифицируются по разрешённому пространству имён — новые ошибки в ранее проходивших файлах
  - Действия для перехода: обновить пакет, прогнать `make deptrac` и `PHPCS`, завести задачи на показанные нарушения; временных переключателей нет
