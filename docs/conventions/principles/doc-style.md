# Оформление документации (Documentation Style)

**Документация конвенций** — на русском, с английским термином в скобках при первом упоминании («перечисление (Enum)»). Этот документ описывает, что выделять обратными кавычками (backticks), а что оставлять обычным текстом, — единый алгоритм вместо «как получилось».

## Общие правила

### Обратные кавычки (`...`) — для кода

Обратные кавычки выделяют литеральный код — всё, что является кодом или ссылкой на конкретный код:

- ключевые слова и конструкции языка: `enum`, `match`, `case`, `function`, `return`, `readonly`;
- имена классов, интерфейсов, трейтов, методов, свойств, констант: `PaymentService`, `__invoke`, `$amount`, `PRIMARY`;
- неймспейсы и пути: `Common\Module\Enum`, `src/Module/Chat/`, `services.yaml`;
- имена файлов и папок: `AGENTS.md`, `tests/`;
- команды и ключи конфигурации: `composer check`, `max_ratio`, `--strict`;
- имена слоёв и паттернов только внутри неймспейс-пути: `Domain\Repository\*`, `Application\Mapper\*` (отдельным словом — обычный текст, см. ниже).

### Без обратных кавычек — понятия и термины обычным текстом

- русский термин: «перечисление», «валидатор», «репозиторий», «контроллер» (понятие, а не код);
- устоявшиеся англоязычные термины из `allowlist`: DTO, UseCase, Enum, Mapper, Helper, PSR, PHPMD, PascalCase, camelCase — употребляются как обычные слова;
- английский термин при первом упоминании — в круглых скобках: «объект-значение (Value Object)».
- общеупотребимые имена артефактов (README, CHANGELOG, LICENSE, AGENTS) как понятие или название документа — без кавычек: «обнови CHANGELOG», «секция Релизы и CHANGELOG»; backticks — только при ссылке на literal-файл (с путём или расширением): «файл `CHANGELOG.md`», «см. `README.md`».

### Англоязычные термины, кальки и глоссы

- Классовые термины конвенций — английским обычным текстом, без транслитераций: Voter, Rule, Grant, Mapper, Helper, CriteriaMapper, FormModel, FormType, CommandBus, QueryBus, Request/Response/Query DTO, Permission/Action Enum (не «маппер», «грант», «продакшн»).
- Устоявшиеся русские программистские слова оставляем русскими: валидатор, репозиторий, контроллер, сервис, маппинг, фреймворк.
- Без кальки с английского: «проверка связанных полей» (не «межполевая валидация»), «классы данных» (вместо буквального «полезная нагрузка» для payload).
- Глосс в скобках избыточен, если русское слово уже передаёт смысл — убираем: «адаптером» (не «адаптером (adapter)»), «устаревший каталог» (не «(legacy)»). Оставляем только при первом упоминании нового понятия: «голосующий объект (Voter)».

### Принцип единообразия

- **`allowlist` не определяет расстановку обратных кавычек** — только семантика (код или понятие). Если термин — ссылка на код, он в обратных кавычках по всему документу, даже если он есть в `allowlist`.
- Имена слоёв и паттернов (Domain, Application, Infrastructure, Integration, Presentation, Repository, …) — термины: отдельным словом пишутся обычным текстом; обратные кавычки — только внутри реального неймспейс-пути (`Domain\Repository\*`).
- Обратные кавычки внутри текста ссылки допускаются: [`psalm.xml`](../examples/psalm.xml).

## Расположение

- Правила применяются ко всей документации в `docs/conventions/` и к корневым `README.md`, `AGENTS.md`.
- Поддерживается проверкой: `validate-language` исключает текст в обратных кавычках из подсчёта англицизмов; единообразие контролируется ревью по чек-листу ниже.

## Почему это важно

- `validate-language` исключает текст в обратных кавычках из подсчёта англицизмов — корректная расстановка снижает шум метрики и убирает ложные срабатывания.
- Единообразие: читатель не спотыкается о «почему `match` в кавычках, а Enum — нет».

## Пример

```markdown
❌ Плохо — код и понятие перемешаны:
Пример использования Enum в match. Размещают в Common\Enum.

✅ Хорошо — код в обратных кавычках, понятие — по-русски:
Пример использования перечисления в `match`. Размещают в `Common\Enum`.
```

## Чек-лист для проведения ревью кода

- [ ] Все код-идентификаторы (классы, методы, ключевые слова, пути, файлы) — в обратных кавычках.
- [ ] Понятия обычным текстом — по-русски; английский термин — в скобках при первом упоминании.
- [ ] Имена слоёв и паттернов отдельным словом — обычным текстом; backticks только внутри неймспейс-пути (`Domain\Repository\*`).
- [ ] `allowlist` не решает расстановку кавычек — только семантика (код или понятие).
- [ ] Англоязычные классовые термины — обычным текстом без транслитераций; устоявшиеся русские слова — по-русски.
- [ ] Нет избыточных глоссов (adapter, legacy, …) и кальки (межполевая валидация, полезная нагрузка).
